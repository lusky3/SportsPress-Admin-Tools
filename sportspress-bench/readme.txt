An installable player and game-night app for SportsPress leagues: your schedule, who is playing, and a spare pool for short teams.

== Description ==

A child module of SportsPress Admin Tools. Bench gives every registered player one link that shows their next game, full season schedule and roster, lets them mark In / Out / Maybe per game, lets a short team call a spare, and keeps a personal calendar feed in step with reschedules. Organizers get a game-night board.

Bench is inert until the "Bench" module is enabled under Settings, SportsPress Admin Tools.

== Installation ==

1. Install and activate SportsPress Admin Tools (the parent framework) and SportsPress.
2. Activate this plugin, then enable the "Bench" module in SportsPress Admin Tools settings.
